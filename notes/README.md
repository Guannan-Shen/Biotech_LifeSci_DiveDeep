# Notes

The project's memory. Kept current every session (rule 4 in `AGENTS.md`).

| File | Content | Update when |
|---|---|---|
| `sessions/YYYY-MM-DD.md` | Goal, work done, decisions, open items, next steps | Every working session |
| `decision_log.md` | Numbered architecture and research decisions with rationale | A design or direction choice is made or reversed |
| `open_questions.md` | Questions waiting on the investor or on data | Asked, answered, or superseded |
| `research_backlog.md` | Ideas, hypotheses and data sources not yet scheduled | An idea comes up |
| `backtests/` | Pre-registered analysis plans and results logs | Before and after every backtest |
